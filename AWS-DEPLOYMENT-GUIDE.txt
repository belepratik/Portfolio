📋 PREREQUISITES
----------------
1. AWS Account (free tier eligible)

⚡ STEP-BY-STEP AWS DEPLOYMENT
==============================

🔧 1. SETUP AWS CLI
-------------------
# Install AWS CLI
https://aws.amazon.com/cli/

# Configure credentials
aws configure
# Enter: Access Key ID, Secret Access Key, Region (us-east-1)

🗄️2. CREATE RDS MYSQL DATABASE (FREE TIER)
-------------------------------------------
# Go to AWS Console > RDS
1. Click "Create database"
2. Choose "MySQL" (8.0)
3. Template: "Free tier"
4. Settings:
   - DB instance identifier: portfolio-db
   - Master username: admin  
   - Master password: [create strong password]
5. DB instance class: db.t2.micro (FREE TIER)
6. Storage: 20 GiB (FREE TIER LIMIT)
7. Connectivity:
   - Public access: YES (for now)
   - Security group: Create new "portfolio-db-sg"
8. Additional configuration:
   - Initial database name: portfolio_db
9. Click "Create database"

🖥️ 3. DEPLOY BACKEND TO EC2 (FREE TIER)
---------------------------------------
# Launch EC2 Instance
1. Go to EC2 > Launch Instance
2. AMI: Amazon Linux 2
3. Instance type: t2.micro (FREE TIER)
4. Security group: 
   - SSH (22) from your IP
   - HTTP (80) from anywhere
   - Custom TCP (8080) from anywhere
5. Create/select key pair
6. Launch instance

# Connect and setup
ssh -i your-key.pem ec2-user@your-ec2-ip

# Install Java 17
sudo yum update -y
sudo amazon-linux-extras install java-openjdk17 -y

# Upload your JAR file
scp -i your-key.pem backend/target/*.jar ec2-user@your-ec2-ip:~/

# Create systemd service with SECURE environment variables
sudo nano /etc/systemd/system/portfolio.service

[Unit]
Description=Portfolio App
After=network.target

[Service]
User=ec2-user
WorkingDirectory=/home/ec2-user
ExecStart=/usr/bin/java -jar -Dspring.profiles.active=prod portfolio-app.jar
Restart=always

# 🔐 SECURE: Environment variables (NOT hardcoded passwords)
Environment=DB_HOST=your-rds-endpoint.rds.amazonaws.com
Environment=DB_PORT=3306
Environment=DB_NAME=portfolio_db
Environment=DB_USERNAME=admin
Environment=DB_PASSWORD=your-secure-password
Environment=SERVER_PORT=8080
Environment=CORS_ORIGINS=http://your-s3-bucket.s3-website-us-east-1.amazonaws.com
Environment=AWS_REGION=us-east-1

[Install]
WantedBy=multi-user.target

# 🔐 EVEN MORE SECURE: Use AWS Systems Manager Parameter Store
# Instead of Environment=DB_PASSWORD=password, your app can fetch from:
# aws ssm get-parameter --name "/portfolio/db/password" --with-decryption

# Start service
sudo systemctl daemon-reload
sudo systemctl enable portfolio
sudo systemctl start portfolio

🌐 4. DEPLOY FRONTEND TO S3 (FREE TIER)
---------------------------------------
# Create S3 bucket
aws s3 mb s3://portfolio-app-[unique-name]

# Build React app with backend URL
cd frontend
echo "VITE_API_URL=http://your-ec2-ip:8080/api" > .env.production
npm run build

# Upload to S3
aws s3 sync dist/ s3://portfolio-app-[unique-name] --delete

# Enable static website hosting
aws s3 website s3://portfolio-app-[unique-name] \
  --index-document index.html \
  --error-document index.html

# Set public read policy
aws s3api put-bucket-policy \
  --bucket portfolio-app-[unique-name] \
  --policy '{
    "Version": "2012-10-17",
    "Statement": [{
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::portfolio-app-[unique-name]/*"
    }]
  }'

🚀 5. OPTIONAL: ADD CLOUDFRONT CDN (FREE TIER)
----------------------------------------------
# Create CloudFront distribution
aws cloudfront create-distribution \
  --distribution-config '{
    "CallerReference": "portfolio-'$(date +%s)'",
    "Origins": {
      "Quantity": 1,
      "Items": [{
        "Id": "S3-portfolio",
        "DomainName": "portfolio-app-[unique-name].s3.amazonaws.com",
        "S3OriginConfig": {
          "OriginAccessIdentity": ""
        }
      }]
    },
    "DefaultCacheBehavior": {
      "TargetOriginId": "S3-portfolio",
      "ViewerProtocolPolicy": "redirect-to-https",
      "TrustedSigners": {
        "Enabled": false,
        "Quantity": 0
      },
      "ForwardedValues": {
        "QueryString": false,
        "Cookies": {"Forward": "none"}
      }
    },
    "Comment": "Portfolio App CDN",
    "Enabled": true
  }'

🔒 SECURITY BEST PRACTICES (CRITICAL)
====================================
❌ NEVER store passwords in application.properties
❌ NEVER commit secrets to Git
❌ NEVER hardcode credentials in code

✅ USE Environment Variables on EC2:
   - Store secrets in systemd service file
   - File permissions: 600 (owner read-write only)
   - sudo chmod 600 /etc/systemd/system/portfolio.service

✅ BETTER: AWS Systems Manager Parameter Store
   - Encrypted storage of secrets
   - IAM-controlled access
   - Audit trails of secret access

✅ BEST: AWS Secrets Manager  
   - Automatic rotation of passwords
   - Integration with RDS
   - Industry standard for production apps

🛡️ PRODUCTION SECURITY CHECKLIST
================================
1. ✅ Use environment variables (minimum)
2. ✅ Restrict RDS security group to EC2 only
3. ✅ Use IAM roles instead of access keys
4. ✅ Enable CloudTrail for monitoring
5. ✅ Regular security updates on EC2
6. ✅ Enable RDS encryption at rest
7. ✅ Use HTTPS for frontend (CloudFront)

💡 REMEMBER: Your current application.properties with hardcoded
   passwords is ONLY for development. Never use in production!
